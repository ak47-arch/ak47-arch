**What I'm building**

[feed_analyser](https://github.com/ak47-arch/feed_analyser) is a local-first capture instrument for X.

You save a post in the place you already read it. The text, the links, the comments you choose, and your notes stay on your machine. Search works offline. An optional local agent can answer a question about one capture. The API key stays in that local service. It never goes to the browser.

The saved posts are a knowledge base. Capture stores them as found. Later tools read the store. They do not rewrite it.

Recent work on that instrument:

- **Lists.** Open a list, see the roster, and read one merged feed. Filter by person or by domain.
- **Links.** A captured URL resolves to the page it points at.
- **Projects.** A list can show the projects those links belong to.

The public repository is the current product. I use it as a daily tool, and I published it as a working example. It does not promise support.

I build it in a private software factory. The factory prepares the change, a review checks it, and I try the product before it lands. The factory stays private. The product is the public part.
